# 易支付插件

适用于本项目的 FastAdmin + ThinkPHP 5 后端，协议按常见彩虹易支付兼容接口实现：

- 下单入口：`submit.php`
- 订单查询：`api.php?act=order`
- 商户参数：`pid`、`key`
- 签名方式：MD5
- 成功状态：仅 `TRADE_SUCCESS`
- 异步通知成功响应：`success`

## 配置

1. 将整个 `addons/yipay` 目录上传到后端相同位置。
2. 在 FastAdmin 后台的插件管理中找到“易支付”，填写支付网关、PID、KEY、默认支付通道、公网回调域名和支付后跳转地址。
3. 当前项目的公网回调域名应为 `https://taxinyiyou.taxinyiyou.com`，支付后跳转地址应为 `https://taxinyiyou.taxinyiyou.com/h5/`。
4. 确认上述回调域名可通过公网 HTTPS 访问，再将“启用支付”改为“启用”。
5. 使用小额订单分别测试下单、支付、自动返回、异步回调和重复回调。

网关可以填写平台根地址，例如 `https://pay.example.com/`，也可以填写完整的 `https://pay.example.com/submit.php`。

默认通道值为：

- 微信：`wxpay`
- 支付宝：`alipay`

所有原来走微信的业务入口现在传入 `yipay`，会使用“默认支付通道”。插件默认把该通道设为 `alipay`，因此不会再依赖微信；如果你的易支付平台需要其它通道，可在后台修改“默认支付通道”。

若平台文档给出的通道值不同，请以平台文档为准修改插件配置。

## 回调与查单

异步回调会校验签名、商户 PID、支付状态、订单号和订单金额，并通过数据库事务与行锁避免重复到账。同步返回页先验签，若平台返回参数不完整或签名缺失，会使用官方 `api.php?act=order` 按商户订单号查单，只有平台返回 `status=1` 才会入账。

前端回到应用后也会调用登录保护的 `payment/sync` 接口主动查单，适用于用户手动返回、异步通知延迟或回调被防火墙拦截的情况。该接口会校验当前账号是否拥有对应业务订单。

支付平台同步返回并确认入账后，会根据业务类型跳回对应页面：普通订单直接进入本次支付的订单详情；打赏和礼物回到对应打手详情；保证金、会员、余额充值和罚款分别回到各自的业务页面。

## 安全校验

异步和同步回调均只接受文档规定的 `TRADE_SUCCESS`，并通过数据库事务与行锁避免重复入账。主动查单接口不会接受客户端提交的金额或支付状态，金额和状态全部以翼支付订单查询结果为准。

## 协议差异

不同“易支付”平台可能使用不同接口路径、签名算法或字段名。如果平台不是彩虹易支付兼容协议，需要根据平台 API 文档调整 `library/Service.php`，不要直接上线测试。
